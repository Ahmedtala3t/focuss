# وضع التركيز — نسخة iOS أصلية (SwiftUI)

نسختان من نفس الكود:

| | **Lite** (`project.yml`) | **كاملة** (`project_full.yml`) |
|---|---|---|
| حساب Apple | **مجاني يكفي** | Apple Developer مدفوع (99$/سنة) |
| مؤقت + عدّ تنازلي + إشعار انتهاء + إبقاء الشاشة منورة | نعم | نعم |
| حجب التطبيقات تلقائيًا (Screen Time API) | لا | نعم |
| قفل الآيفون على التطبيق | عبر **الوصول الموجَّه** (دليل داخل التطبيق) | حجب مباشر للتطبيقات المختارة |

Apple تمنع Screen Time API (الحجب) على الحسابات المجانية، لذلك الـ Lite تعتمد على ميزة **الوصول الموجَّه** المدمجة في iOS، وهي تقفل الجهاز على تطبيق واحد فعليًا.

## تشغيل نسخة Lite على الآيفون (حساب مجاني)

على الـ Mac (Xcode 15+):
```bash
brew install xcodegen
cd ios_native
xcodegen                      # ينتج FocusLock.xcodeproj من project.yml
open FocusLock.xcodeproj
```

في Xcode:
1. افتح Settings ← Accounts وسجّل بحساب Apple ID الخاص بك.
2. اختر Target `FocusLock` ← Signing & Capabilities ← Team: **Your Name (Personal Team)**.
3. غيّر الـ Bundle Identifier لاسم فريد (مثل `com.اسمك.focuslock`)، لأن `com.example` محجوز.
4. وصّل الآيفون بكابل. على الآيفون: الإعدادات ← الخصوصية والأمان ← **وضع المطوّر** ← شغّله (يعيد التشغيل).
5. اختر الآيفون من الأعلى في Xcode واضغط ▶ Run.
6. أول مرة: على الآيفون الإعدادات ← عام ← VPN وإدارة الجهاز ← اختر حسابك ← **Trust**.

ملاحظة: التطبيقات الموقّعة بحساب مجاني تنتهي صلاحيتها بعد **7 أيام**؛ توصّله بالـ Mac وتضغط Run مرة ثانية فيتجدد.

## إعداد الوصول الموجَّه (مرة واحدة)
الإعدادات ← تسهيلات الاستخدام ← الوصول الموجَّه ← شغّله ← إعدادات الرمز السري، وفعّل "اختصار تسهيلات الاستخدام". بعد "ابدأ التركيز" اضغط الزر الجانبي 3 مرات ← ابدأ. للخروج: 3 ضغطات + الرمز. من الخيارات يمكنك ضبط "حد الوقت" على نفس المدة.

## النسخة الكاملة (حجب التطبيقات) — تحتاج حساب مدفوع
```bash
xcodegen --spec project_full.yml
open FocusLock.xcodeproj
```
- فعّل Team المدفوع للـ targets `FocusLock` و`FocusMonitor`.
- للتجربة على جهازك تظهر قدرة **Family Controls**؛ للنشر على App Store اطلب الموافقة من Apple: https://developer.apple.com/contact/request/family-controls-distribution
- أقل مدة جلسة 15 دقيقة، ولا تعمل على المحاكي.
- لإنتاج `.ipa`: Product ← Archive ثم Distribute.

## ملاحظات
- لم أستطع بناء المشروع هنا (بيئتي Linux)، فقد تحتاج تعديلات صغيرة عند أول بناء؛ ابعت لي نص أي خطأ يظهر في Xcode وأصلحه.
- المستخدم يقدر دائمًا يوقف الوصول الموجَّه أو يسحب إذن Screen Time، فالتطبيق يرفع الاحتكاك ولا يقدّم قفلًا مطلقًا.
